# Laboratorio V - APIs REST con Spring Framework

## Presentacion
Proyecto practico correspondiente a la creacion de 10 APIs REST independientes utilizando **Spring Boot** y **Maven**, implementando listas en memoria, control de excepciones y estructura desacoplada (Controller-Service-Model).

## Estructura del Proyecto
- **Lenguaje:** Java 17
- **Framework:** Spring Boot 3.x
- **Gestor de Dependencias:** Maven
- **Control de Versiones:** Git & GitHub

## Endpoints Desarrollados
1. `/api/productos`
2. `/api/estudiantes`
3. `/api/libros`
4. `/api/empleados`
5. `/api/peliculas`
6. `/api/cursos`
7. `/api/vehiculos`
8. `/api/tareas`
9. `/api/clientes`
10. `/api/pedidos`
